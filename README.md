I build things that have to survive somewhere unfriendly — 30 m of water, Mach-adjacent airflow, or a 220 °C hotend.

- 🌊 **Mechanical lead**, Turqua ROV — TEKNOFEST Unmanned Underwater Systems. Pressure housings, O-ring sealing, thruster layout, hydrodynamics.
- 🚀 **CAD designer**, TurBos Rocketry — TEKNOFEST rocket competition. Owner of the recovery and payload sections of the design report.
- 🛠️ Day-to-day: Fusion 360, OpenFOAM, Python, a Bambu P1S that rarely sleeps.

### What I'm building here

| Project | What it is | Status |
|---|---|---|
| `teknofest-report-kit` | Generate and lint TEKNOFEST design reports (KTR/CDR/FRR) from a YAML spec | 🚧 |
| `teknocalc` | Unit-safe Python library for ROV and rocket preliminary sizing | 🚧 |
| `fusion360-toolkit` | Fusion 360 add-in: batch export, parametric variants, drawing automation | 🚧 |
| [awesome-teknofest](https://github.com/asermas/awesome-teknofest) | Curated resources for TEKNOFEST teams | ✅ |
